# 素材ブリッジ

スマホで撮った写真・動画を、選んだフォルダへまとめてコピーするAndroidアプリです。

## このアプリでできること

- 「撮影をはじめる」を押すとカメラが開きます。撮り終わって「撮り終わったので送る」を押すと、撮った写真・動画が保存先のフォルダへ自動でコピーされます
- 以前に撮った素材も、まとめて選んで送れます
- 保存先にGoogle Driveのフォルダを選んでおけば、AIがそのフォルダから素材を取りに行けます。チャット画面に動画を1件ずつアップロードする手間がなくなります
- アプリ自体はネット通信をせず、Googleアカウントにも接続しません。素材が作者のサーバーを通ることもありません

## 対応環境

- Android 10以降
